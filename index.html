ABOUT

How Room Hunt Works

Room Hunt is designed to connect people searching for accommodation with owners who want to publish property details in one place.

For users

Search a location, browse properties within the selected radius, use filters, save favourites, request visits and unlock contact access according to the available plan.

For owners

Create an owner profile, verify a mobile number, upload property photos, optionally add a video, choose facilities, set availability and manage listings.

Safety and privacy

Owner contact details are hidden by default. Production deployments should use server-side authentication, database rules, secure file storage, payment verification and abuse reporting.

Security & Privacy

  • Owner phone numbers remain hidden until access is granted.
  • Client-side validation prevents incomplete listings in this demo.
  • Production authentication, payment verification and storage must be server-side.
  • Browser permissions are controlled by your browser or device; these preferences are Room Hunt settings only.
